# CareerOps Architecture

CareerOps is a job and recruiter intelligence workflow for relevant CSE, AI/ML, software, data, and campus opportunities.

## Initial Scope

- Discover and normalize job opportunities.
- Deduplicate companies, jobs, and public professional contacts.
- Track verification metadata.
- Synchronize approved records with Smartsheet.
- Apply transparent relevance and priority rules.

## Security

- Never commit API keys or tokens.
- Use environment variables and local secret storage.
- Respect provider terms, rate limits, and privacy requirements.
- Store only publicly available professional information with source URLs.
